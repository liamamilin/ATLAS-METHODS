# 本机 Skill 资料库

按领域、专题和仓库查看已经转换的 Skill。搜索覆盖标题、任务目标、摘要和来源。详情展示适用条件、步骤、产出与限制，可以复制做法，或打开固定版本的 GitHub 来源和本机原文。

选择「软件开发与架构」会展开带条数的二级分类。每条记录按主要工作用途归入一个分类，优先看标题、任务目标和入口目录名，再参考摘要。信号冲突或内容明显跨领域时放到「待细分」。二级分类可以与关键词和来源筛选一起使用。已有法律类专题也显示在对应领域下。

在仓库根目录使用现有标准化 Python 环境运行：

```bash
python3 library/build.py
python3 library/serve.py --port 8765
```

打开 [本机资料库](http://127.0.0.1:8765)。服务只监听本机地址。完整资料库和原文由本机提供，生成的 SQLite 索引保存在 `data/library/catalog.sqlite3`。

## GitHub Pages 公开目录

[公开目录](https://liamamilin.github.io/ATLAS-METHODS/) 可以搜索 Skill 名称、分类和仓库，详情列出 GitHub 固定版本来源。部署源为 `gh-pages` 分支根目录。

在仓库根目录构建最新快照，然后导出到一个空目录：

```bash
python3 library/build.py
python3 library/export_pages.py /tmp/atlas-pages-release
```

公开目录包含条目标题、目录标签、来源元数据，以及 `public-overviews.json` 逐条选出的公开整理摘要。每条摘要核对本机记录的来源路径和固定提交，并保留上游作者与许可。公开搜索可查标题、已公开摘要和来源路径，长横线、连字符和空格可互换。公开详情提供「在本机查看完整整理」入口。

更新公开站点时，把生成的 `index.html`、`app.js`、`pages_catalog.js`、`style.css`、`catalog.json` 和 `.nojekyll` 提交到 `gh-pages`。完整转换内容和原文仍用本机资料库访问。

后续转换落盘后再运行一次 `python3 library/build.py`，然后刷新页面。生成器读取启动时的已保存结果，原子替换目录。已打开页面的来源链接使用固定来源身份，代表记录变动时，旧链接仍可解析到当前代表。

目录从实际存在并与采集索引匹配的 SkillRecord 生成，复用首批 40 条和 `full-001` 正式结果。材料包合并比较固定版本的入口、关联文件 Git blob 和供给范围，额外识别能核对的 Markdown 格式变化。原转换与来源均保留，已核验的历史去重关联在代表条目的来源页可回查。存在重要内容差异或证据不足的记录各自保留。

分类沿用[既有内容分布抽样](../docs/content-distribution-20261118.md)中的类别。已有样本标签优先，其余按标题、任务目标和摘要初分，部分来源有可识别的专题。归属不明的条目保留在「待归类」。详情标出分类依据和记录审阅状态。

对于原先待归类的条目，明确的标题用语可补充分组，例如 Git 分支管理、Skill 制作、产品定价和演示文稿制作。标题明确描述应用连接与自动化的 Rube MCP 条目纳入「工具集成与自动化」。两类以上线索冲突时仍保留待归类。
