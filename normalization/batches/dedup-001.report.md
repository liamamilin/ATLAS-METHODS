## 实现与依据

- 从固定采集索引读取正文与关联资料，复用 Git blob、正文 SHA256 和供给范围校验。输入、遗漏及未供给文件的清单用于比对。
- 先识别材料相同的副本，再检索同名和文本特征接近的候选，由现有模型判断关键操作、条件、权限、数值和限制是否相同。原文代表以 source_package 元数据保存，转换结果继续采用 SkillRecord v0.1.1。
- 去重结束后写入 plan.jsonl、unique.queue.jsonl 及逐项判定。原转换器按原批次与断点转换保留来源，已转换来源继续复用。代表成功后重复项关联实际结果；代表失败时，关联项保留 pending_duplicate。
- 全部来源、比较请求、原响应、用量与关联证明保存在本机持久目录。自动判断的候选检索与语义结论仍可能漏判或误判。
