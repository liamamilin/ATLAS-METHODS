| --- | --- | --- |

| 领域、专题、搜索、任务与工具筛选 | 页面脚本与 `library/test_library.py`；合成 Chrome 冒烟 | 同上，不能用合成目录代替 46,599 条生产目录 |
| 详情中的步骤、限制、审阅状态和固定来源 | 合成页面截图；Mac 接口已读到详情和来源 | Mac 上打开一条已归类记录和一条保留记录 |
| 分类覆盖在重建后仍在 | Mac：427 条拟归类生效为 426，1 条因代表更换挂起；27 条保留。云端合成测试覆盖冲突与回滚 | 那 1 条挂起由本机继续处理 |

| 公开导出 | 导入和重建不会调用 `export_pages.py` | 不要为这批分类发布 |

合成 Chrome 测试只证明页面代码能渲染一个两条目录。它没有打开 Mac 上的生产服务。

本机服务已经在 8765 端口时，在仓库根目录执行。此命令不写数据库、不导入、不重建、不另开端口：

```bash
cd /Users/milin/Documents/ChatGPT/ATLAS-METHODS
python3 library/accept_local.py --require-server --page --shots /tmp/atlas-accept
```

没有 Chrome 时去掉 `--page`。退出码 0 表示目录文件与正在响应的服务一致；加了 `--page` 时还表示打开了一条真实详情，并能看见审阅状态和固定来源。退出码 1 表示服务未响应，或服务与文件不一致。退出码 2 表示目录文件不存在。截图只写到 `--shots` 给出的目录。
