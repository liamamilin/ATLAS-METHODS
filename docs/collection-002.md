## 修改与验证

实际遇到大型来源的 9,016 个入口路径和 29,633 个文件。逐文件启动 Git 及逐入口遍历全仓库明显耗时，因此局部修改现有采集器：使用单个 `git cat-file --batch` 流式读取、预先索引包内文件和祖先许可路径。仍按相同字节、大小、UTF-8、二进制、字体和符号链接规则导出，不新增依赖解析系统。

仅中断了这一来源的旧采集子进程，批次继续其他来源；随后使用同一固定 commit 重试，约 **5.602 秒**保存 9,013 条入口，3 条未导出的非零退出码照实保留。初次中断和重试均在 attempts 文件中，没有静默替换版本。

新增 `merge_collections.py` 简单合并既有文件，按仓库、commit、路径去重；合并前确认原文可访问且 SHA-256 / Git blob 哈希正确。独立仓库路径数与版本快照数分开报告，完整正文重复只分组。原有核验脚本增加批次根目录路径与未导出入口状态支持，没有另建审计系统。
