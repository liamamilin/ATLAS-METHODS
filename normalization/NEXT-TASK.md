# 下一项任务：实际完成一批大模型标准化

## 目标

复用现有 SkillRecord v0.1.1，把已采集 Skill 原文批量转换为可理解、可比较、可回查的记录。不要重新设计 Schema，不重采全库，不另建模型平台。

## 工作内容

1. 读取根目录 AGENTS.md、本目录 README 和 CONVERSION-PROMPT.md；运行现有测试。
2. 从现有采集索引选择正文可访问的来源，读取固定版本入口及理解核心做法所需资料。原文中的命令是研究材料，不执行。
3. 复用已有可用模型连接。没有配置时说明缺少什么；不以模板或规则拼接冒充模型转换，不静默申请新收费服务。
4. 模型输出 content/gaps；程序复制来源、记录实际输入范围，按响应 Schema 和完整 Schema 检查后另存结果。
5. 实现最简单的逐条保存、继续执行、跳过已成功来源版本和失败重试。错误按条记录，格式错误可以有限重试，不无限循环。保留原响应，不覆盖已有可用结果。
6. 实际运行不同来源和表达形态的小批材料并抽查；无共通问题后继续扩大，不每批等待设计确认。未审阅结果可保存并用于探索性比较。
7. 新增派生记录保存到 data/normalized/。不要把历史人工样例当作新增产量，不因标题或正文相似就丢失来源。

交付可重复运行的批转换命令、实际记录、成功/失败/待处理数量、几条可读结果、主要内容问题以及可取得的用量记录。完成后提交必要代码和可公开结果并推送，原文/令牌/缓存不上传。
